# Powiat Opatowski

Nowoczesna, responsywna strona informacyjna Starostwa Powiatowego w Opatowie.

## Zawartość

- sprawy urzędowe i szybkie kontakty,
- władze i wydziały,
- jednostki powiatowe,
- informacje o regionie,
- dane kontaktowe,
- pełna obsługa telefonów i komputerów.

Strona nie zawiera działu ogłoszeń.

## Uruchomienie

Otwórz plik `index.html` w przeglądarce lub włącz GitHub Pages dla gałęzi `main` i katalogu głównego.
